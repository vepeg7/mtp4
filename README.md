## Запуск

```bash
python main.py
python -m pytest
```

`main.py` вызывает все пять пунктов с постоянными seed, поэтому повторный запуск печатает то же самое.

## Модули

`logged` (`logging_deco.py`) перед вызовом пишет INFO в логгер `lab.calls` и включает в текст имя функции. `functools.wraps` сохраняет имя обёрнутой функции. Наружу возвращается её обычный результат.

`ranged_random` и `iter_ranged` (`random_range.py`) дают целые из отрезка. Обе границы включены: выпасть могут и `low`, и `high`. Оба пути используют `random.Random(seed).randint`, поэтому при одном seed список и генератор совпадают.

`sum_with_reduce` (`reduce_sum.py`) складывает числа через `functools.reduce`. Пустой список возвращает 0.

`endless_records` (`endless.py`) бесконечно отдаёт словари `{"n": int}`. Внутри `while True`, после нескольких `next` поток не кончается.

`TokenIterator` (`iterator.py`) — отдельный класс с `__iter__` и `__next__`. Элементы идут по порядку, за последним приходит `StopIteration`.

Случайный диапазон: обе границы включительно.
